Privacy

Last updated 4 November 2026

Wisp and wisp-mac.com are made and run by one person, Chris.

The app

Wisp has no analytics, no crash reporting, no updater and no account. It does not send anything about you or your Mac to anyone, including me.

The only network traffic Wisp causes is reverse DNS lookups. When the Network page or an app's drawer is open, Wisp asks your Mac's own resolver for the names of the hosts your apps are connected to, the same lookup nettop or Activity Monitor would need. The lookups go wherever your Mac normally sends DNS queries.

What Wisp keeps stays on your Mac, in ~/Library/Application Support/Wisp: a day of history by the minute, a year by the hour, alert history, storage scan results and settings. Delete that folder and it is gone.

Some pages read files other tools keep on your Mac, and only while you have the feature on or the page open:

  • Coding Agents reads Claude Code's session logs in ~/.claude to count tokens used today.
  • Plan limits, if you turn them on, add Wisp to Claude Code's status line and read Codex's session logs in ~/.codex/sessions. Wisp never reads either tool's sign-in. Turning plan limits off restores your previous status line.
  • Storage measures folders on your disk and, with Full Disk Access, the parts of your Library macOS protects. It reads sizes and dates, not file contents.

The wisp command and the MCP server answer on a socket only your user account can open. An AI assistant you connect to the MCP server sees what the command prints, and anything it sees is handled under that assistant's own privacy policy.

This website

wisp-mac.com is a static page hosted on Vercel. It doesn't set cookies or run analytics. Vercel keeps standard server logs (IP address, time, page requested, browser), as described in Vercel's privacy policy. The page loads the GSAP animation library from jsDelivr, which also sees your IP address under its own policy.

Downloads come from GitHub Releases and Homebrew, which have their own policies.
