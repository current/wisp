Changes Wisp makes to your Mac

Wisp only changes things when you ask it to, and asks first where the change is hard to undo:

  • Quit and Force Quit end the app you picked. Force Quit can lose unsaved work.
  • Storage moves the items you pick to the Trash after a confirmation. It never empties the Trash. Check the Trash before you empty it.
  • Containers can stop or restart a container you pick.
  • Plan limits edit the statusLine setting in each Claude Code settings file and keep a copy of the original in ~/Library/Application Support/Wisp/claude-settings-backup. Turning plan limits off puts the old setting back.
  • An AI assistant connected to the MCP server can ask Wisp to quit an app. Wisp shows you the request, and nothing quits unless you click Quit.

Unsigned builds

Wisp is signed ad hoc and not notarized by Apple. The Homebrew cask removes the quarantine flag after installing, and the release notes list each zip's SHA-256 so you can check it. You can also build Wisp from source.
